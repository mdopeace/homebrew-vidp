# Mdopeace Vidp

## How do I install these formulae?

`brew install mdopeace/vidp/<formula>`

Or `brew tap mdopeace/vidp` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mdopeace/vidp"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
